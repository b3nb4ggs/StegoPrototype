# to set up python environment:
This project runs on Python 3
Check python version using command: python --version
If "python --version" shows you have Python 2.7 or less, use the command "python3" in place of "python" in the commands below
for example, if you have multiple python versions and the command instruction is:
"python average.py encode --message cat.jpg --lsb 1 --pixelno 3 --method avg"
then use the command below instead to make sure that the program is being executed with python3:
"python3 average.py encode --message cat.jpg --lsb 1 --pixelno 3 --method avg"

**important**
To run this program, you will need to install Pillow package
Linux/Mac: run bash setup.sh (if permission issue need to chmod u+x setup.sh)
        OR run python -m pip install Pillow
Windows: python -m pip install Pillow

---------
# average method:
- view help menu
python average.py -h

- encode using average.py (average lsb method) 
python average.py encode cover.bmp --message cat.jpg --lsb 1 --pixelno 9 --method avg
# stego.png or stego.bmp will be output file - cover with hidden message

- decode using average.py (average lsb method) 
python average.py decode stego.bmp --lsb 1 --pixelno 9 --method avg
# output message will be named message_extract.xxx where xxx is extension (for cat.jpg -> "message_extract.jpg" will be output message file)
# in this example, output will be "message_extract.jpg"
